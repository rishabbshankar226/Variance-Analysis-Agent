## Method

- **Fixtures** (`tests/fixtures/chrome_qa/`): `fav_net`, `unfav_net`, `mixed_sign`,
  `edge_values` (zero/negative budgets, 3–4 decimals), `names` (`R&D_Costs`,
  `Sales & Marketing`, `<b>Bold</b>`, `Café`, duplicates, emoji), `structure` (a
  reconciling `Total Revenue` subtotal, a neutral row, two rows with no Type), and
  `large` (5,000 generated rows). `examples/sample_variance.csv` and `sample_eur.csv`
  were also used. All runs use thresholds `$10k or 5%`, USD, period `Q3 2026`.
- **Discovery**: Python probes and a chip crawler (every chip in every response, depth 2,
  per fixture) found candidates. Each one was then reproduced in Chrome by typing or
  clicking as a user would. JavaScript was used only to read DOM text and console output.
- **Evidence**: screenshots are in `docs/qa/evidence/` (`E*` = defect on `main`,
  `V*` = re-verified fix, `R*` = Render). The intake-loop GIF (2.3 MB) was kept out of
  the repo; the screenshot `E07` shows the same loop.
- **Note on 375 px**: the window resize did not change the tab viewport, so the layout was
  measured in a 375 px iframe of the page. It had no horizontal overflow (tables scroll
  inside their own wrapper).

## Issues

### [Critical] C1 — Memo "Strategic Takeaway" contradicts the numbers
- Area / fixture / phase: memo / `sample_variance`, `mixed_sign`, `edge_values` / 2D
- Steps: upload → `Q3 2026` → `$10k or 5%` → `USD` → `memo`
- Observed (sample): "Review Subscription Revenue immediately. Unfavorable variances in this category exceeded budget limits by USD 15,500.00, driving total net operating margins into negative territory…"
- Expected (oracle): Subscription Revenue is **F +15,500**; largest unfavourable is Marketing Expense (+13,000); actual margin 28.6% (positive); net −8,500.
- Evidence: `E02_memo_takeaway_sample.jpg`; the live site shows the same text: `R01_render_memo_takeaway.jpg`
- Suspected cause: `handlers.py` memo built its own `FinancialAuditSummary` with `top_material_item = material_rows[0]` (largest absolute, whatever its direction); `financial_commentary.py` templates asserted "negative territory", "Revenue outpaced", "widening margins", "Solid cash posture" and "no unresolved variances" unconditionally.
- Fix: the memo now calls the same `generate_verified_commentary()` as the CLI. Every sentence is emitted only when a fact (net sign, top favourable/unfavourable item, margin direction, operating profit sign, material count, unclassified count) supports it.
- Acceptance test: `test_memo_takeaway_matches_oracle_and_cli[*]`. Re-verified: `V01_memo_takeaway_fixed.jpg`.

### [Critical] C2 — CLI `--commentary` reports the wrong direction
- Area: `deterministic_conditioning/variance_bridge.py` / `unfav_net`, `mixed_sign`, `sample_variance` / 2D-2
- Steps: `variance-agent <fixture> --period "Q3 2026" --dollar-threshold 10000 --percent-threshold 5 --commentary -o out.md`
- Observed: `unfav_net` (net −45,000): "net spending tracked closely with modeled targets. Balanced performance… leaving no unresolved variances". `mixed_sign` (net −12,000, operating loss) and `sample_variance` (net −8,500): "Revenue outpaced expectations cleanly… widening operating margins. Solid cash posture."
- Expected: an unfavourable posture naming the largest unfavourable item (Subscription Revenue / Payroll Expense / Marketing Expense).
- Suspected cause: `variance_bridge.py:36` summed raw `actual − budget` over material rows, so expense overruns counted as gains; the residual check read `result.drivers`, which does not exist, so FIN-R1 could never fire.
- Fix: net comes from the aggregates (`revenue.variance − expenses.variance`); residual comes from `row.driver_evidence.reconciles`; labels are Markdown-escaped in the CLI report (M4).
- Acceptance test: `test_cli_commentary_matches_oracle[*]`, `test_commentary_flags_unreconciled_driver_residual`. Before/after transcripts are under Improvements.

## Deterministic conditioning engine

- **Truthfulness**: see C1/C2. `tests/test_chrome_qa_regressions.py` now fails if any
  takeaway names an item in the wrong direction, or claims outperformance, a beat or
  widening margins on a net-unfavourable period. It also fails on "negative territory"
  with a positive margin, "no unresolved variances" when material items exist, or any
  mention of cash.
- **CLI parity**: memo takeaway == `safe_inline(generate_verified_commentary(result)[0])`
  for all 7 fixtures.

## Remaining risks

1. **Shared single-threaded server.** One stalled client can still pause every visitor for
   up to 15 s, and all visitors share one session (one user's `reset` or upload clears
   another's). Per-visitor sessions plus a threaded server need a design decision because
   they change public behaviour.
2. **Commentary coverage.** The truthfulness guard covers the takeaway. The memo body,
   tldr and run-rate prose are still hand-built f-strings with their own percent logic
   (M7, M8, M12), and nothing yet checks them against the oracle sentence by sentence.
3. **Benchmark** (M13) still reports metrics on hand-written text. `BENCHMARK_REPORT.md`
   should not be cited as evidence of engine quality until it scores real output.

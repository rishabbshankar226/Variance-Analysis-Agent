## Confirmed defects and fixes

| Priority | Defect and reproduction | Fix |
|---|---|---|
| High | `--output` or `--audit-json` can overwrite the input or type map; identical report/audit paths destroy one output. | Validate all output paths before writes, including symlink and hardlink aliases; hash the source before output. |
| High | JSON budgets `9007199254740992.01` and actuals `9007199254740992.02` produce zero variance. | Parse JSON fractional numbers directly into Decimal. |
| High | Ragged CSV records and populated unnamed columns silently lose or shift data. Duplicate JSON keys silently replace values. | Reject ambiguous records, blank-header data, and duplicate JSON keys. |
| High | A total of 240 is discarded despite detail actuals of 120; incomplete totals look verified. Nested summary scopes are guessed. | Require one category summary to reconcile to its details within $0.01; reject multiple summaries with ambiguous scope. |
| High | Net Income and Operating Income are inferred as additive revenue. An explicit Unclassified type is overridden by a Sales label. | Keep profit labels and nonblank unrecognized types Unclassified unless an explicit supported classification/type map applies. |
| High | A +$1 variance with components totaling -$0.80 is marked supported because balance-based tolerances are too loose. | Require the components to reconcile to the variance as well as modeled balances. |
| Medium | Changing two nonmaterial actuals from 100/100 to 101/99 leaves the analysis fingerprint unchanged when no source hash is supplied. | Include all analyzed rows in the fingerprint input without expanding the public audit payload. |
| Medium | Both Budget and Plan can be supplied; one silently wins. | Reject multiple aliases for a required field. |
| Medium | A null line-item name becomes the literal string None. | Reject null labels. |
| Medium | Interior blank Excel rows abort an otherwise valid workbook; unnamed columns lose data; read-only workbooks are not explicitly closed. | Skip empty Excel rows, reject populated unnamed columns, close workbooks in finally. |
| Medium | Missing files and malformed input cause uncaught tracebacks. | Report expected file, parsing, and Decimal errors through argparse with exit code 2. |

## Compatibility and boundaries

The stricter input validation intentionally rejects previously accepted ambiguous
files. Supply detail-only data for nested hierarchies; the tool cannot infer
subtotal membership. Inferred profit metrics remain excluded until the user
supplies an appropriate classification or removes those nonadditive rows.
Fingerprint values change under the new recipe.

The review does not establish the absence of every possible bug. Decimal
arithmetic still uses Python's current Decimal context (normally 28 significant
digits); arbitrary-precision financial input is not promised. Source hashing
before/after loading detects ordinary concurrent edits, but is not a filesystem
snapshot. Multi-file output is not a transactional write. No live external agent,
production dataset, or deployment environment was supplied.

## Token-efficient follow-up workflow

Run the suite once, then read only failing tests and their implementation paths.
Reproduce each new defect at the smallest real API/CLI boundary. Run focused tests
after each fix, then the full suite and lint once before review. Keep source rows
out of LLM context; use the compact audit JSON for materiality and driver facts.

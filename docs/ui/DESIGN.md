# Variance Analysis Agent: interface design

Status: skeleton (Phase 0). Phase 1 fills every section; each decision names the alternative it rejected.

## Direction

- Reference class: a quiet financial workbench (the restraint of Linear, Stripe's dashboard, a well-set annual report).
- Page pattern: _Phase 1._
- One job per screen: _Phase 1, per screen._

## Tokens

### Colour

_Phase 1: a grey ramp of about nine steps per theme, one accent, favorable and unfavorable colours distinct from the accent, attention colour. Light and dark both ship and follow the system setting._

| Token | Light | Dark | Use |
|---|---|---|---|

### Type

_Phase 1: the stack, the scale (at most 6 sizes, 3 weights), tabular figures, monospace on code spans only._

### Space, shape, depth

_Phase 1: the 4 px scale, at most 2 radii, one overlay shadow, hairline borders._

### Motion

_Phase 1: durations at most 200 ms on opacity and transform; loader cycle at most 1.2 s; reduced motion stops both._

## Components

_Phase 1 onward: header and mark, drop zone, message, chips, input bar, intake panel, headline strip, results table, drill-down, driver breakdown, earnings table, error, loading, empty._

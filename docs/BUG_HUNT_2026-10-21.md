# Variance Analysis Agent bug hunt, 2026-10-21

Reviewed baseline: `77a628a` (`origin/main`, after PRs #17 to #21). Scope: the whole chatbot: the
command line, the chat server and its single-page UI, assisted intake (CSV, TSV, Excel, PDF), the
analysis and audit engine, and the auxiliary `deterministic_conditioning/` package.

Earlier audits ([2026-09-28](BUG_HUNT_2026-09-28.md), [quality follow-up](QUALITY_AUDIT_FOLLOWUP.md),
[diagnostic follow-up](DIAGNOSTIC_FOLLOWUP_2026-10-02.md), [institutional audits](INSTITUTIONAL_AUDIT_2026-10-19.md),
[Chrome QA](qa/CHROME_QA_2026-10-21.md)) fixed dozens of defects, so this pass looked for new ones and for
siblings of already-fixed classes. Three read-only reviewers audited the chat logic, the engine and the
server/UI/tooling; the strongest findings were then reproduced independently before any fix. Fixes were made
test-first (the failing run was seen) in four workstreams with disjoint files, then merged and re-verified together.

## Confirmed defects and fixes

Severity: **P0** wrong numbers, crash, freeze or cross-site exposure; **P1** wrong or misleading result in a
common path; **P2** polish with a real effect. "Reproduced" means a probe against the baseline showed it.

### Engine and intake

| Pri | Defect and reproduction | Fix |
|---|---|---|
| P0 | Assisted intake read amounts it could not parse as 0 and carried on. `Service Revenue,500,"500.00-"` or a blank Actual gave Actual `$0.00`, a 100% shortfall, exit 0, no warning; strict mode rejected both. Reproduced. | Unreadable or blank Actual cells stop the run (CLI exit 2, chat message) with up to ten rows and columns to fix. A trailing minus, U+2212, full-width digits and NBSP are read as the number they stand for and reported. |
| P0 | Label inference filed `Sales Commissions`, `Income Taxes`, `Sales Salaries` and `Sales Tax` under Revenue (an overrun showed Favorable and inflated Total Revenue) and added `Income Before Taxes` and `Comprehensive Income` as revenue. Reproduced. | One shared classifier (`classification.py`) for analysis and signed-ledger detection: cost nouns make an Expense, profit subtotals stay Unclassified, revenue stated net of returns stays Revenue. User-approved rule change. |
| P1 | Subtotal detection was quadratic: 0.6 s, 2.5 s, 9.6 s for 2,000, 4,000, 8,000 assisted rows (strict: 0.4 s at 8,000); hours at the 100,000-row cap on the hosted instance. Reproduced. | A tolerance-grid index makes it near-linear (0.05 s at 8,000 rows), checked against the original algorithm (3,000 random ledgers in a one-off run; 400 are kept as a test). |
| P1 | `build_audit_record` ignored the policy Decimal context: precision 4 with `ROUND_DOWN` changed the coverage percent and the fingerprint. Reproduced. A PDF figure that failed to parse left `InvalidOperation` set in the caller's context. | Both run under the fixed context. |
| P1 | A PDF with one unreadable figure (a footnote marker) came back unshaped but with sign resolution and subtotal removal switched off. | The shaper reports whether it ran; the ordinary checks apply, and an unreadable figure stops with a PDF-appropriate message. |
| P1 | `--mapping` audits echoed the mapping, not the run: `unit_scale: null` after a title-driven ×1000, a header row the CLI ignored, `flipped_line_items: []` after a flip, `accounting_dashes` always 0. | Audits record what intake applied; a mapping adds only its period selection, rules and digest. |
| P1 | Hand-edited mappings raised tracebacks (`KeyError`, `TypeError`), accepted `unit_scale` 0, negative or `abc`, and produced audits that failed the schema. | Mappings are validated (typed fields, positive scale, canonical rule spelling, 1 MiB cap); exit 2 with "Mapping file …". A `--type-map` overriding rules is announced. |
| P1 | The assisted CSV reader split on lines (breaking quoted newlines), had no row/column/cell limits, and read `;` or tab files as one column; undecodable bytes became U+FFFD. | One reader with the strict loader's limits, delimiter detection, physical row numbers, and strict UTF-8/UTF-16/Windows-1252 decoding with a note. |
| P2 | Repeated Actual columns (`Actual`, `Actual YTD`) or identical Budget headers were resolved by taking the first; `Category` beat `Account Description`; `Contract Value` matched as an Actual column. | Intake stops and names the columns with their positions; whole-word header matching; account names beat a grouping Category. |
| P2 | Hidden worksheets could win sheet ranking; `Price Index` was ranked as a cover sheet; an oversized sheet gave only "could not be opened safely". | Hidden sheets rank last; whole-name cover matching; the error names the limits. |
| P2 | `FY99` ordered after `FY00`; `--type-map` rejected `opex`, `cogs`, `Unclassified`; output paths differing in case collided on macOS and Windows; data errors printed a 9-line usage banner; `--check-only` said "1 rows"; zero-width characters were invisible; error rewriting mangled `Q3--Q4` and `sales_tax`; `$(1,234)` was not read. | Fixed, each with a test. |
| P2 | A stray `PORT` variable made `--chat` bind all interfaces. | Only `--hosted` or `RENDER` does; an invalid `PORT` is a clear error. |

### Chat logic

| Pri | Defect and reproduction | Fix |
|---|---|---|
| P0 | One chat message of whitespace or digits froze the single-threaded server: `what if` plus 200 spaces took 3.6 s and grew with about the fourth power of the length; `/status` timed out, so Render's health check would fail. Reproduced over HTTP. | Routing works on a normalised copy (NFKC, folded quotes and spaces) capped at 500 characters after the pasted-table branch; patterns are linear. |
| P0 | `top`, `why` or `detail` plus 4,301 digits raised `ValueError`; over HTTP the connection dropped. Reproduced. | Digit runs are bounded where parsed. |
| P0 | A failed re-upload replaced the source name and bytes before parsing: later audits named the bad file and its hash. Per-file state (type choices, period, thresholds, currency, mapping) leaked into the next upload, so an earlier "Misc Thing is Revenue" overrode an explicit Expense row. Reproduced. | A file is read before it replaces the session; a successful upload resets per-file state. |
| P1 | "show me the summary", "give me …", "why is marketing over budget?", "unfavourable", "top 3 expenses", curly quotes and NBSP mis-routed; `top 0` showed "Top 1"; "download report now" wrote a file named `now`. | Routing and path capture fixed; export paths need a path-like token. |
| P1 | "Upload a different file" had no handler in intake steps; free-text period answers disagreed with the analysed data; duplicate names gave a "Multiple matches" dead end; `expense status` hid the largest overspends; `metrics` counted subtotals; `sheet 3` matched by substring. | Fixed. |
| P1 | Profitability, run rate, sensitivity, what-if, compare and utilization ignored unclassified rows silently; what-if accepted unclassified targets and drops over 100%; run-rate months were wrong for `Jan-Jun 2026` and `H1 FY26`. | Caveats added; targets and ranges guarded; period parsing fixed. |
| P1 | CSV export wrote `=HYPERLINK(...)`, `+cmd\|`, `@SUM` cells verbatim. | Text label cells are guarded with a leading `'`; numeric columns untouched. |
| P1 | Knowledge text contradicted the engine (materiality "AND/OR", SEC/SOX compliance, "data never leaves your environment" on a shared host); "EBITDA" labelled revenue minus all expenses. | Rewritten to match the engine; "operating margin". |
| P2 | Percents divided by a signed budget (negative-cost budgets); thresholds truncated (`0.25%` shown as `0.2%`); the TL;DR called a zero variance a beat, saving or outperformance; "Keep blank budgets" changed nothing. | Fixed; the chip is removed. |

### Server and front end

| Pri | Defect and reproduction | Fix |
|---|---|---|
| P0 | An upload with a non-ASCII filename (`Café.csv`, `預算.csv`) raised `TypeError` in the multipart parser; the connection dropped and the UI said "Failed to fetch". Reproduced in the browser. | A small multipart splitter that handles raw UTF-8 names and caps a body at 8 parts. |
| P0 | Any web page could drive the local server: `Access-Control-Allow-Origin: *`, no Origin, Host or Content-Type check; a `text/plain` POST from another origin was accepted, and with path exports enabled it could make the server write a file. Reproduced. | A POST's `Origin` must equal `Host` (this also covers `/upload`); local mode answers only loopback hosts (DNS rebinding); `/message` requires JSON; no wildcard CORS. Hosted mode compares hostnames (a port the proxy appends to `Host` is fine) and also accepts `X-Forwarded-Host` and `RENDER_EXTERNAL_HOSTNAME`; `/status` stays open. |
| P0 | A handler exception dropped the connection; a lone surrogate crashed serialisation. | JSON 500 with the traceback on stderr; ASCII-escaped replies. |
| P1 | A 4 MiB hostile `sharedStrings.xml` peaked near 7× its size; a multipart body of ~678k empty parts reached ~550 MiB (the free tier has 512 MB). | Chunked pre-scan, worksheets only, per-member caps, part cap. |
| P1 | Staged downloads survived reset, were unbounded and shared; `#` in a period truncated the URL. | Capped (16 entries, 48 MiB), cleared on reset and re-upload, percent-encoded. |
| P1 | Two copies of the 1,200-line page; in a wheel the server looked for the root copy outside the package. | One packaged copy served via `importlib.resources`, extracted into `chat.js` and `chat.css` with a strict CSP; `check_distribution.py` and `check_installation.py` verify the wheel, the sdist and a running installed server. |
| P1 | UI: 6 of 11 steps labelled; a reload overwrote the server's step; error and 413 replies rendered an empty bubble; a single-line input dropped the newlines of pasted tables; no request lock or timeout; no `aria-live`, labels or keyboard access to upload and sorting; contrast 2.5 to 3.7:1; `100vh`; a dead font `@import`. | Fixed (WCAG AA contrast, multi-line input, deadline, keyboard access, `dvh`). |
| P2 | Content-Length accepted `5_0`; replies lacked `nosniff`, `no-store` and `Referrer-Policy`. | Fixed. |

## Evidence

- Tests: **955** on `origin/main` (with the `pdf` extra installed) to **1,743** on the combined branch (35 new or
  extended test files, 74 in all). Each workstream was also run alone: 1,143 engine, 1,114 server and UI, 1,201 chat
  logic, 1,146 tooling, all from the same baseline.
- `ruff check .`, `mypy --strict src/variance_agent scripts deterministic_conditioning`, `compileall` and `pytest`
  pass; the tooling workstream also ran them in clean 3.11 and 3.13 environments installed the way CI does, built the
  wheel and sdist, ran `twine check` and `check_distribution.py`, and ran `check_installation.py` in clean venvs.
- Differential test: the indexed subtotal detector equals the original on 3,000 random ledgers (one-off) and 400 (kept as a test).
- Live checks in the built-in browser against the combined branch: a non-ASCII upload, the unreadable-cell message,
  "Upload a different file", a full guided analysis (commission and tax lines land in Expenses), a pasted table, a
  reload mid-intake that keeps the step, a 20,000-space message answered in 6 ms with `/status` still responsive,
  a `text/plain` POST refused (415), a cross-origin POST and a rebound `Host` refused (403), and the CSP,
  `no-store`, `nosniff` and `Referrer-Policy` headers.
- Reproduce locally:

python -m pytest -q
python -m ruff check .
python -m mypy --strict src/variance_agent scripts deterministic_conditioning
python -m compileall -q src tests scripts deterministic_conditioning

## Compatibility and boundaries

Behavior changes are listed first in the [changelog](../CHANGELOG.md): unreadable amounts stop the run, cost
labels are Expenses, a new upload resets the chat, cross-origin requests are refused, `--chat` hosts only by flag or
`RENDER`, and the unused `Phase.AWAITING_SHEET_CHOICE` and `Phase.AWAITING_HEADER_CHOICE` are gone.
The classification and intake changes alter reports and audit fingerprints for affected files; no pinned contract
fixture was affected.

Not verified or not changed:

- **Render.** The hosted deploy itself was not tested. A server started the way Render starts it (`RENDER` and `PORT`
  set) answered the health check with an internal `Host`, accepted a browser POST whose `Host` carries a proxy-appended
  port, one routed through `X-Forwarded-Host`, and one matched by `RENDER_EXTERNAL_HOSTNAME`, and refused foreign and
  look-alike origins. Watch the first deploy anyway.
- **Training scripts** (`train_dpo_hf.py`, `train_unsloth_dpo.py`, Axolotl) need `torch` and TRL; the suspected TRL
  keyword drift is documented, not changed. The flat sampling fields of the OpenAI-compatible client were not
  tried against a live vLLM or TGI server.
- **TypeScript.** `chat.js` carries `// @ts-check` and JSDoc, but `tsc --checkJs` was not run (only `node --check`
  and Node-run tests of its helpers).
- **PDF extraction** was checked on the synthetic fixtures only.
- **Audit record.** Trailing-minus reads and text-encoding conversions appear in the intake summary and on stderr
  but have no audit field; adding one needs a new schema version.
- **Deliberately left:** per-visitor sessions and a threaded server (every visitor still shares one session and the
  server is single-threaded); a repo-wide `E501` or bugbear ruff rule (725 and 41 hits, mostly in files other branches
  edit); `Total Revenues` and `Total Operating Expenses` still ask for an explicit Row Kind in strict mode;
  `parse_decimal` still accepts `1_000`; `what-if` and `compare` still use the first of several identical line names.
- The reviews do not establish the absence of every possible bug.
